# Shrine Forest — WebGPU

A fantasy shrine-and-forest scene you can fly through in your browser: a vermilion torii gate, a stone-paved approach lined with lanterns, a shrine building with a shimenawa rope, a great sacred tree, and a dense cedar forest with god rays and a small stream.

Everything is generated by code at load time — no images, no 3D models, no sound files, no libraries. The whole world is a single self-contained `index.html` rendered directly with WebGPU, with ambient sound synthesized live through the Web Audio API.

**▶ Play it: https://kouki0822.github.io/shrine-forest-map/**

## Requirements

- A browser with WebGPU support:
  - Desktop: current Chrome or Edge with hardware acceleration enabled.
  - Android: Chrome 121 or newer on a supported GPU.
  - iPhone / iPad: iOS / iPadOS 26 or newer (Safari).
- If WebGPU or a GPU adapter is missing, the page says so and explains what to try, instead of showing a blank screen.
- Nothing to install; it also works offline once `index.html` is downloaded.

## Controls

### Keyboard and mouse

| Action | Keys |
| --- | --- |
| Move | `W` `A` `S` `D` |
| Look | Mouse (pointer lock, click the scene first) |
| Down / Up | `Q` / `E` |
| Accelerate | `Shift` |
| Jump to a viewpoint | `1` – `6` |
| Sound on / off | `M` |
| Change detail level (reloads) | `L` |
| Hide text / show stats | `H` / `F` |

### Touch (phones and tablets)

| Action | Gesture |
| --- | --- |
| Fly forward | Touch and hold anywhere on the scene |
| Steer (look) | Slide the held finger: left/right turns, up/down tilts. Flying follows where you look. |
| Accelerate | Put a second finger down while the first one is held |
| Next viewpoint | `◎` button |
| Sound on / off | `♪` button |
| Change detail level (reloads) | Detail button (shows `Low` / `Med` / `High`) |

Lift the first finger to stop. If you lift the first finger while the second is still down, the second takes over steering.

## Detail levels

There are three detail levels: **Low**, **Medium** and **High**. They differ in render resolution, shadow-map size, light-shaft quality, particle counts and how far ferns, hydrangeas and tree detail are drawn.

- Chosen automatically on first load: phones and tablets start at Low, or at Medium if the browser reports 8 GB or more of device memory (`navigator.deviceMemory`, Chrome only). Desktops start at High.
- Phones and tablets also cap the device pixel ratio and use dynamic resolution, so the render resolution drops when frames run slow and recovers when there is headroom. High (desktop) renders at full resolution.
- If a load crashes or the GPU device is lost, the next load starts one level lower. The choice is remembered in `localStorage`.
- To change it by hand, use `L` or the detail button. You can also force a level for one visit with `?q=low`, `?q=medium` or `?q=high`.

## Verification modes (for testing)

- `?shots` — renders the six fixed viewpoints and downloads `pose-1.png` … `pose-6.png` at the window's resolution (use a 2560×1440 full-screen window for the target spec).
- `?bench` — runs the scripted 60 s fly-through and shows a frame-time report: GPU timestamp queries where the browser supports them, plus a requestAnimationFrame frame-interval log (average, 99th percentile, max), with a JSON download.
- `?record=60` — records the scripted fly-through to `flythrough.webm`.

These modes always use the High level unless `?q=` is given.

## Status

Work in progress. This is an experiment following the method of Abyssal Garden (a swimmable underwater world in one 97 KB HTML file): one detailed prompt to Claude Code (Opus), everything procedural, and a separate visual-critic subagent that reviews only the renders.

Smartphone support has been added in code: touch controls, automatic detail levels, adapter fallbacks, a device-pixel-ratio cap and dynamic resolution. It has **not yet been verified on a real phone**. The visual-critic pass and the performance measurement on the target PC (RTX 3070 Ti, 2560×1440) are still pending.

The initial prompt used to generate the scene is in `prompt.txt`.
