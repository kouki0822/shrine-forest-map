# Shrine Forest — WebGPU

A fantasy shrine-and-forest scene you can fly through in your browser: a vermilion torii gate, a stone-paved approach lined with lanterns, a shrine building with a shimenawa rope, a great sacred tree, and a dense cedar forest with god rays and a small stream.

Everything is generated by code at load time — no images, no 3D models, no sound files, no libraries. The whole world is a single self-contained `index.html` rendered directly with WebGPU, with ambient sound synthesized live through the Web Audio API.

**▶ Play it: https://kouki0822.github.io/shrine-forest-map/**

## Requirements

- A browser with WebGPU support (current Chrome or Edge recommended). If you see "This scene needs WebGPU", update your browser or switch to Chrome / Edge.
- Nothing to install; it also works offline once `index.html` is downloaded.

## Controls

| Action | Keys |
| --- | --- |
| Move | `W` `A` `S` `D` |
| Look | Mouse (pointer lock, click the scene first) |
| Down / Up | `Q` / `E` |
| Accelerate | `Shift` |
| Jump to a viewpoint | `1` – `6` |

## Status

Work in progress. This is an experiment following the method of Abyssal Garden (a swimmable underwater world in one 97 KB HTML file): one detailed prompt to Claude Code (Opus), everything procedural, and a separate visual-critic subagent that reviews only the renders. The currently published version is the first draft — touch controls / detail levels for smartphones and the full visual-critic pass are still being added.

The initial prompt used to generate the scene is in `prompt.txt`.
